# Suraj BTP Project: Robo-Matter Duality

This repository contains Suraj's Bachelor Thesis Project work on Robo-Matter, active magnetic Magbot simulations, chiral dynamics, light-field control, and phase-like collective behavior.

## Folder Structure

- `BTP-1/`: Initial simulation work, MSD analysis, single/multiple Magbot animations, wall/no-wall cases, and magnetic interaction demonstrations.
- `BTP-2/`: Extended Robo-Matter study with 100--150 Magbot simulations, phase-state scripts, generated phase plots, research material, and the compiled BTP report.
